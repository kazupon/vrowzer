    Interface SvcWorker

    Service Worker interface that extends ServiceWorkerGlobalScope

    This interface provides transparent access to all native Service Worker APIs while adding version management capabilities.

    Readonlysuspended

    suspended: boolean

    Whether the service worker is suspended (circuit breaker engaged).

    When true, fetch handlers should bypass their logic and return fetch(event.request) directly.

    Example

    sw.addEventListener('fetch', (event) => {
      if (sw.suspended) {
        event.respondWith(fetch(event.request))
        return
      }
      // Normal fetch handling...
    })
