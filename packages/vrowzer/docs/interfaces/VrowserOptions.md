# Interface: VrowzerOptions

VrowzerOptions defines the configuration options for [Vrowzer](../functions/Vrowzer.md).

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-basepath"></a> `basePath?` | `string` | Preview base path (default: '/__preview__/') |
| <a id="property-serviceworkerscope"></a> `serviceWorkerScope?` | `string` | Service Worker scope (default: '/') |
| <a id="property-serviceworkerversion"></a> `serviceWorkerVersion?` | `string` | Service Worker version for cache management (default: 'vrowzer-v1') |
