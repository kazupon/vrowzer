# `@vrowser/service-worker`

> [connect](https://github.com/senchalabs/connect) for the browser

## 💿 Installation

```sh
# npm
npm install --save @vrowser/connect

# pnpm
pnpm add @vrowser/connect

# yarn
yarn add @vrowser/connect

# deno
deno add npm:@vrowser/connect

# bun
bun add @vrowser/connect
```
